# Funnel principles · Hims density, parent voice

Parents arrive tired. Match **Hims**: almost every screen is **one sentence** of prose (visuals and row labels don’t count).

## Sentence budget

| Count | When |
|-------|------|
| **1** | Most screens — headline only |
| **2** | A few (e.g. GPA gap headline pair, ack) |
| **3** | **Only** qualify / approved (step 19) |

## Voice

- About **their kid** (“they/their”), not “you” on kid facts
- Premium, calm — **no** binary rain, `prep_path`, terminal jargon
- Plain labels: Last scored, not score band; Tutor solves, not Mistake Found

## Per screen rules

| Allow | Ban |
|-------|-----|
| 1 headline (sans) | Fraunces, paragraphs, disclaimers on every screen |
| 1 hero visual | Scroll, locked buttons |
| Honest quiz data only | Grade, exact scores, target schools, deadlines we didn’t ask |
