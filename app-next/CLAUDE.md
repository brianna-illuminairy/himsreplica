# illuminairy SAT funnel — context for a fresh session

This is the **active** app (Next.js, App Router, plain JSX, port 3001). Root-level `*.jsx`/`*.html` are the legacy prototype — ignore unless asked.

**Read first:**
- `../README.md` — flow, screen map, key files, run instructions
- `../DECISIONS.md` — decision log + the open next-steps punch list (start here)
- `../FUNNEL-PRINCIPLES.md` — copy rules (3 sentences max, parent voice, no marketer-speak, no icons, "does it help convert?")

**Run:** `npm run dev` → http://localhost:3001 · jump to screens with `?step=` (e.g. `?step=i-diag`).

**Workflow:** commit + push each change to branch `claude/tender-euler-grYPq`. Build with `npm run build` before committing.
